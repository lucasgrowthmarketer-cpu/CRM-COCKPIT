# Frontend — Industrial Decision Cockpit

React 18 + Vite (via craco) + Tailwind + shadcn/ui.

## Scripts

- `yarn start` — dev server sur http://localhost:3000
- `yarn build` — build production dans `build/`
- `yarn test` — tests

Le backend est attendu sur `REACT_APP_BACKEND_URL` (voir `.env`).
Par défaut : `http://localhost:8000`.
